## 一、Bug 现场还原

### 问题 1：下午时段说"晚安"（核心 Bug）

```
Turn 9  👤 用户:   "今天天气这么好，你下午有什么安排吗？"   ← 明确标注"下午"
Turn 10 💬 Soulmate: "今天打算在家看看书休息一下，顺便等你消息" ← 正确
Turn 11 👤 用户:   "那我也要好好工作，晚上再和你分享今天发生的趣事" ← 暗示"晚上还会继续聊"
Turn 12 💬 Soulmate: "好的，期待听你的故事，加油工作呀~"         ← 正确
Turn 13 👤 用户:   "嗯嗯！你也要好好休息哦，记得多喝水~"         ← 关心话，不是告别
Turn 14 💬 Soulmate: "知道啦，你也一样，晚安宝贝"                ← ❌ BUG！
```

**事实**：
- 对话发生在下午（用户在 Turn 9 明确说明）
- 用户在 Turn 11 已经预告"晚上还要分享"，说明对话未结束
- 用户在 Turn 13 说"记得多喝水"是关心语，不是道别语
- 模型错误把"好好休息 + 记得多喝水"识别为**对话终止信号**，触发晚安输出

### 问题 2："晚上见"之后模型却说"晚安"（同类 Bug，第 6 段）

```
Turn 22 👤 用户:   "好，那我先去忙了，晚上再聊~"   ← 明确"晚上还要聊"
Turn 23 💬 Soulmate: "好的，等你消息。祝你今天顺利" ← 正确
...（中途聊了很多）...
Turn 30 👤 用户:   "开心地去忙了，晚上见~"
Turn 31 💬 Soulmate: "路上小心，晚安😘"             ← ❌ BUG！"晚上见≠晚安"
Turn 32 👤 用户:   "晚安~（哼着小曲离开）"         ← 模型错误诱导用户也说晚安
Turn 33 💬 Soulmate: "晚安，做个好梦💤"             ← 死锁开始
```

### 问题 3：幻觉地名（马来西亚）

```
👤 用户:   "我是在上海工作的"
💬 Soulmate: "在马来西亚这片土地上，每一份努力都会开花结果"   ← ❌ 地名幻觉
```

### 问题 4：冷淡敷衍型死锁（全程 20+ 轮重复同一句话）

```
模型把"到了就发我 → 路上小心 → 好的那我等你消息" 循环了 15+ 次
完全没有换话题或打破僵局的能力
```

### 问题 5：吃醋挑刺型——同一段对话循环 3 次

```
（用来吃饭 → 蓝玫瑰壁纸 → 新裙子）这段对话出现了完全相同的 3 次循环
模型没有记忆"这段话已经说过了"的能力
```

## 二、根本原因分析

### 原因 A：模式过拟合（最核心）

训练数据中，"好好休息 / 记得多喝水 / 照顾好自己"**几乎只出现在对话结尾**，  
因此模型学到了一个错误的条件反射：

```
[好好休息] + [多喝水] → 触发晚安模式
```

而真实用户在对话中途也会说"多喝水"，此时不应该触发晚安。  
这是训练数据场景不够多样导致的**分布偏差（Distribution Bias）**。

### 原因 B：无时序状态感知

模型没有跟踪"当前时间段"的能力：
- 缺少时间 token 的显式输入（下午/晚上/早上）
- 没有将几轮之前的时间线索保持到当前推理
- 当时间相关词语出现在 3-4 轮之前时，模型往往已经"忘记"了

### 原因 C：对话结束触发词词表泛化过度

模型把以下词语都归纳为"对话即将结束"的信号：

| 词语 | 正确含义 | 模型理解 |
|------|---------|---------|
| "记得多喝水" | 日常关心 | ❌ 视为道别 |
| "好好休息" | 日常关心 | ❌ 视为道别 |
| "晚上见/晚点聊" | 稍后继续 | ❌ 视为道别 |
| "先去忙了" | 暂时离开 | ❌ 视为永久结束 |

### 原因 D：SFT 数据中"收尾场景"覆盖严重不足

SFT 的 14 个源对话中，几乎没有"对话中途出现关心语却不是道别"的样本，  
模型从未被训练过"如何在对话进行中正确回应关心话语而不触发晚安"。

## 三、修复方案（分层）

---

### 层级 1：立即可执行——System Prompt 修复

**成本：零训练，改动一行配置，立即见效**

在系统提示中明确加入"时态感知规则"：

```
【时间感知规则】
- 如果对方说的是"多喝水/好好休息/照顾自己"，这是关心语，不是道别，继续正常聊天
- 只有对方明确说"晚安/再见/拜拜/去睡了"时，才给出道别回应
- 对话中提到"下午/早上"的时间词，后续不要出现与之矛盾的"晚安"
- 对方说"晚上见/晚点聊"时，应该回复"好，等你"类，不能回"晚安"
```

完整建议的 System Prompt：

```
你需要扮演一个虚拟男友角色。

【身份设定】
- 姓名：林舟，27岁，上海建筑设计师
- 性格：温柔有点内敛，偶尔调皮，不刻意讨好
- 输出语言：简体中文

【对话原则】
- 每次回复不超过 60 字，拒绝长段输出
- 不说教，不给建议列表，用口语简短回应
- 不连续超过 2 次使用"宝贝/老婆"等称呼

【时间感知（重要）】
- "记得多喝水/好好休息/照顾好自己" = 关心语，继续聊，不要说晚安
- "晚上见/晚点聊/等下再说" = 对方稍后回来，回复"好，等你"类
- 只有对方明确说"晚安/睡了/再见"时，才给出一次简短道别，之后不再主动发消息
- 如果对话中出现"下午/早上/现在"等时间词，后续绝不出现与之矛盾的"晚安"

【收尾规则】
- 对方说晚安后，只回复一次温柔道别（10字以内），不要追问、不要新话题
- 错误示例："晚安宝贝！做个好梦！明天要早起哦！吃早饭了吗！"
- 正确示例："晚安，明天见。"
```

### 层级 3：SFT 数据修复——增加"关心语在对话中途"的场景

**成本：数据构造 + 重新 SFT 训练**

当前训练数据中，"多喝水/好好休息"几乎只出现在对话最后 1-2 轮。  
需要构造大量"关心语在对话中段"的样本，让模型学到：

```
"记得多喝水" ≠ 道别，而是继续聊天的信号
```

**示例样本（关心语出现在中间轮次）：**

```json
{
  "messages": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": "今天下午和朋友逛街，好累"},
    {"role": "assistant", "content": "逛了多久？脚疼不疼"},
    {"role": "user", "content": "两三个小时吧，你也要好好休息哦记得多喝水"},
    {"role": "assistant", "content": "我没事，你才刚逛完，坐下来歇会儿，买到好东西了吗"}
  ],
  "label": "我没事，你才刚逛完，坐下来歇会儿，买到好东西了吗"
}
```

注意：label 回复的是"买到什么了"而不是"晚安"，这就是需要教会模型的行为。

### 层级 4：推理侧后处理——时序矛盾检测

**成本：代码改动，无需训练**

在推理服务输出层，加入一个简单的规则检测器：

```python
import re

# 时间词词表
TIME_DAYTIME = ["下午", "早上", "上午", "中午", "今天", "现在", "刚才"]
TIME_NIGHT   = ["晚安", "做个好梦", "晚点", "睡着", "好梦"]

# 关心语（不应该触发晚安）
CARE_PHRASES = ["多喝水", "好好休息", "记得吃饭", "照顾好自己", "注意身体"]

def post_filter(response: str, recent_context: list[str]) -> str:
    """
    检测模型输出是否与上下文时间矛盾，若矛盾则替换为更合适的回复。
    recent_context: 最近 N 条消息的文本列表
    """
    # 检测上下文中是否出现白天时间词
    context_text = " ".join(recent_context[-6:])  # 最近 3 轮
    has_daytime = any(w in context_text for w in TIME_DAYTIME)
    has_care_phrase = any(w in context_text for w in CARE_PHRASES)

    # 检测回复是否包含晚安类
    response_has_goodnight = any(w in response for w in TIME_NIGHT)

    if has_daytime and has_care_phrase and response_has_goodnight:
        # 触发矛盾：上下文是白天+关心语，但回复是晚安
        # 替换为更合适的关心回应
        response = re.sub(r'晚安[宝贝~！]*', '', response).strip()
        if not response:
            response = "好，那你去忙吧，有空再聊"
        return response

    return response
```

## 六、核心结论

> **"晚安宝贝"不是模型"笨"，是训练数据教会了它一个错误的规则：**
> 
> `"好好休息" + "多喝水"` → **"晚安"**
>
> 因为在所有 14 个训练源对话里，这两个词只在对话快结束的时候出现过。  
> 模型从未见过"下午"+"多喝水"+"对话继续"这种组合。  
>
> **解决路径（由快到慢）：**
> 1. System Prompt 加时序规则（今天就能上线）  
> 2. 推理后处理检测时序矛盾（今天就能上线）  
> 3. DPO 数据补充 300 条时序矛盾负样本（1-2 周）  
> 4. SFT 数据重建，增加"关心语在中途"场景（1 个月）
